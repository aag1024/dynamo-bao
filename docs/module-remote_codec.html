remote/codec

Wire codec for procedure arguments and results.

Everything that crosses the executor boundary is plain JSON. Model rows travel as { $model: "<ModelName>", data: { <field>: <value> } } holding only the model's declared fields, with:

  • DateTimeField, CreateDateField, ModifiedDateField, TtlField: epoch milliseconds (TtlField is stored in seconds and converted).
  • BinaryField: { $binary: "<base64>" }.
  • StringSetField: an array of strings.
  • Every other built-in field: its stored value, which is already JSON.
  • A custom field: its stored value if that is plain JSON; otherwise the row is refused with a CodecError naming the model and field.

Any other non-JSON value (Date, Map, Set, Buffer, class instance, function, NaN, ...) is refused rather than letting JSON.stringify change it silently.

Description:

  • Decode an encoded row into the model's stored representation (the shape of instance._dyData: dates as epoch ms, TTL in seconds, binary as bytes, string sets as arrays). Model.fromRemote builds on this. Fields the receiving model does not declare are dropped, so a row from a newer bundle still hydrates.
