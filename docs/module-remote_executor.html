remote/executor

The executor: a fetch handler that runs envelopes of procedure calls next to DynamoDB.

Request: { v: 1, operationId, requestId?, actor?, calls: [{ id, proc, tenant, args?, actor?, scope? }] } Response: { v: 1, placement: { colo, region }, calls: { [id]: outcome } } Outcome: { ok: value, capacity, ms } | { error: { name, message, ... }, capacity, ms }

Envelope-level failures (ingress, malformed envelope, budget) answer with a non-200 status and { v: 1, error: { name, message } }; no call ran.
