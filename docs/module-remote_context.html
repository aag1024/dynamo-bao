(inner) fresh(fn) → {Promise.<T>}

Description:

  • Run fn in a nested batch context: its own loader cache (so reads go to DynamoDB, not the outer cache) and its own capacity accumulator. When it settles, its capacity is added to the outer context's total, and rows it read or wrote replace the outer cache's entries (rows it deleted are evicted), so a later find in the outer context sees them. This is the "re-read after a lost conditional write" pattern.
