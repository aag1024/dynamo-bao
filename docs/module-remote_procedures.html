(inner, constant) REPLAY_CLASSES

Description:

  • What a resend after an unknown outcome does. Frozen vocabulary: see tutorials/11-remote-procedures.md.

    • idempotent: no writes, or writes whose repeat has no further effect.
    • conditional: every write is a guarded state transition, so a repeat fails its condition and the procedure reports that.
    • needs-ledger: an unguarded write or a counter; the procedure keeps its own marker keyed by ctx.operationId. The client never resends it.
